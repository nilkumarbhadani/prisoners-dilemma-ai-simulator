# 🎯 Advanced Prisoner’s Dilemma Strategy Simulator

An interactive AI-powered Game Theory simulator built using Python and Gradio that demonstrates strategic decision-making, adaptive agent behavior, Nash Equilibrium, and probabilistic learning in the classic Prisoner’s Dilemma environment.

---

## 📌 About The Project

This project was developed as part of the **Foundations of Artificial Intelligence (FAI)** coursework at **IIT Jodhpur**.

The main goal of this simulator is to explore how different intelligent and non-intelligent agents behave in repeated Prisoner’s Dilemma interactions. The system compares multiple strategies across several rounds and analyzes cooperation, betrayal, risk minimization, and long-term utility optimization.

The project combines concepts from:

- Artificial Intelligence
- Game Theory
- Multi-Agent Systems
- Probability & Decision Making
- Strategic Optimization

A lot of effort went into designing the logic, simulation flow, strategy behavior, UI interaction, testing different outcomes, and documenting the theoretical analysis behind each strategy.

## 🧠 Implemented Strategies

### 🤝 Always Cooperate
A simple baseline strategy that always chooses cooperation regardless of the opponent’s behavior.

### ⚠️ Always Betray
A defensive minimax-style strategy that continuously defects to avoid exploitation.

### 🔁 Tit-for-Tat
Starts with cooperation and then mirrors the opponent’s previous move. One of the most effective strategies in iterated Prisoner’s Dilemma scenarios.

### 🎲 Random Strategy
Selects actions randomly with equal probability and acts as a stochastic reference agent.

### 📊 Naive Bayes Predictor
An adaptive probabilistic agent that estimates opponent behavior using transition probabilities and expected utility optimization.
